# Nexo UV 0.1.0

Pacotes do addon para download direto pelo GitHub:

- [NexoUV-0.1.0.zip](NexoUV-0.1.0.zip) — formato extension, Blender 4.2+.
- [NexoUV-0.1.0-legacy.zip](NexoUV-0.1.0-legacy.zip) — instalação tradicional.

Abra o ZIP no GitHub e use **Download raw file**. No Blender, escolha
**Preferences > Install from Disk** e selecione o ZIP sem descompactar.

Pacote Python único, sem executáveis externos, preparado para macOS Intel e
Apple Silicon, Windows e Linux. Validação executada no Blender 4.3.2/Linux;
as demais plataformas ainda precisam de execução nativa.

Recriação independente que usa os solvers UV do Blender, com unwrap, costuras,
partes, UDIM, relax, simetria, stacking e bake. Não reproduz o motor OptCuts.
O Python do addon, logo e licença GPL-3.0-or-later estão dentro dos ZIPs.

Os hashes em `SHA256SUMS` verificam a integridade dos arquivos.
